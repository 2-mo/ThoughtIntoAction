from embodied import Robot

with Robot.sim(viewer=True) as robot:
    q = robot.q
    q[0] += 0.1
    robot.movej(q)
让第一个关节转动 0.1 rad。

MoveJ 输入绝对关节位置；末端路径由关节运动决定。
