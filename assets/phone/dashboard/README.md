# Dashboard Assets

`models/arx5` contains the X5 visual meshes copied from
[`real-stanford/arx5-sdk`](https://github.com/real-stanford/arx5-sdk) commit
`8ccbf0aa8d4288f2721c41a735e5ac4c389bb13b`. They are used only for the
read-only, live dashboard model. The upstream MIT license is included in
`ARX5_SDK_LICENSE`.

The local Three.js runtime and helper modules are from `three@0.161.0`; its
MIT license is included in `THREE_LICENSE`.
