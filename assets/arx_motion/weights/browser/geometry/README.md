# Third-party camera mesh

`intel-realsense-d405.stl` is the Intel RealSense D405 aluminum evaluation
case mesh from `realsense2_description` 4.55.1. It is copied without geometry
modification from:

`reference_projects/ROS2_AC-one_Play/realsense/src/realsense2_description/meshes/d405.stl`

The corresponding package identifies Intel's LibRealSense ROS Team as the
maintainer and licenses `realsense2_description` under Apache License 2.0.
The browser applies the millimetre-to-metre scale and official D405 URDF frame
offsets at runtime.
