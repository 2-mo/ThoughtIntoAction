# 网页控制台

安装、证书信任和第一次手动操作见
[src/frontend/README.md](../src/frontend/README.md)。本文档说明
末端目标位姿编辑，以及从 Mac 通过 Tailscale 直接访问的推荐流程。

## 末端目标位姿编辑

首次使用先安装控制依赖并重新启动网页：

```bash
UV_PROJECT_ENVIRONMENT=.venv-handeye uv sync --only-group handeye
UV_PROJECT_ENVIRONMENT=.venv-web uv sync --only-group web
./arx5 web-tailnet
```

“XYZ 末端”页会在 TCP 目标处常驻 6DoF 操作器。默认只显示红、绿、蓝三个
世界坐标正向平移箭头，拖动按 `0.5 mm` 吸附；按 `R` 切换为绕夹爪局部 XYZ
的三个旋转环，按 `G` 返回平移。拖动期间以节流的只读 IK 连续刷新半透明
机械臂，松开后再请求带轨迹的正式预览；`Enter` 只确认当前编辑阶段，`Q/E`
仍可沿夹爪进近轴微调 Roll，`F` 聚焦目标，`Esc` 恢复当前编辑阶段。

白色小点表示真实 TCP，半透明夹爪表示目标位姿。目标编辑只更新 Ghost 和右侧
绝对 XYZ/quaternion，不发送真实运动；连接后完成编辑会进行 IK 预览，仍须由
用户点击“执行预览”才能移动机械臂。实时 Ghost 使用的 `preview_xyz_live` 只
计算显示姿态，不会调用实时伺服或真实运动接口；目标编辑页继续禁用伺服开关。

官方 X5 的 7 个 STL 网格按固定上游提交哈希保存在浏览器 Cache Storage 中。
第一次仍需下载约 `13.4 MB`；之后刷新会直接读取持久缓存。模型版本改变时缓存键
也会改变并重新下载；缓存不可用或条目损坏时会自动回退网络和页面内置低模。

夹爪姿态属于 TCP quaternion，使用“旋转”模式调整；开闭是独立的一维开度，
位置控制只用于预张开，接触物体时使用限扭矩夹取。回参考真实执行期间，锁定的
TCP 操作器会跟随机械臂反馈移动，结束或中止后重新同步到实际末端。

## Mac 通过 Tailscale 直接访问（推荐）

机械臂主机运行：

```bash
./arx5 can-up
./arx5 web-tailnet
```

首次使用时，Mac 下载并信任 ARX5 本地 CA。将地址替换为启动命令显示的地址：

```bash
curl -k https://<tailscale-ip>:8000/arx5-local-ca.crt \
  -o ~/Downloads/arx5-local-ca.crt
sudo security add-trusted-cert -d -r trustRoot \
  -k /Library/Keychains/System.keychain ~/Downloads/arx5-local-ca.crt
```

然后用 Chrome 打开 `./arx5 web-tailnet` 输出的完整地址（包括 `?token=...`）。
令牌保存在 `runtime/web-pairing-token`，不要发给不需要控制机械臂的人，也不要
把带令牌的完整地址写进仓库或聊天记录。

如果不能安装本地 CA，仍可使用 `./arx5 web` 和原来的 SSH 隧道方式。已经为 LAN
模式安装过 ARX5 本地 CA 的 Mac 不需要重新安装证书。

## Mac 手势遥操作

按以下顺序操作：

1. 在机械臂主机运行 `./arx5 can-up` 和 `./arx5 web-tailnet`。
2. 在 M3 Max 上用 Chrome 打开命令输出的 HTTPS 地址，允许使用 Mac 摄像头。
3. 连接机械臂，选择 `Hand`；先不要打开“机械臂跟随”，移动双手并用半透明 Ghost
   验证基座 XYZ、手掌旋转和绿色安全盒方向。
4. 方向正确后打开“机械臂跟随”。左手张开连续 5 帧后，以机械臂当前位置和左手
   姿态为零点接合；保持左手张开并移动或旋转，机械臂相对跟随。左手收拢即平滑停车。
5. 右手握拳连续 3 帧关闭夹爪；右手张开连续 3 帧恢复设置的张开宽度，默认 `40 mm`。
6. 首次只用“精细”档和清空的工作区；验证丢手、释放离合、页面隐藏、断线、网页
   急停与实体急停后，才可切换“快速”档。

默认安全盒为基座坐标 `X 0.15–0.65 m`、`Y -0.35–0.35 m`、
`Z 0.08–0.55 m`，边界内侧 `30 mm` 开始降速。服务端连续 `200 ms` 收不到新目标
时会同时制动机械臂和夹爪。闭合扭矩允许 `0.05–0.25 N·m`，默认 `0.15 N·m`。
“精细”档 TCP 线速度上限为 `0.03 m/s`，“快速”档为 `0.10 m/s`；服务端还会
独立限制旋转、关节速度、加速度、跃度并验证 IK。

视觉工具栏在“手势控制”和“手眼标定”之间切换。选择手眼标定会先停止遥操作并
等待停车响应；标定进行中不能切回手势工具。Mac 摄像头只供手势估计，D455 RGB
仍作为场景视图；手势模式隐藏 D455 深度伪彩色画面以减少界面拥挤。

## 操作要点

手动区会用官方 X5 网格实时显示反馈姿态。默认的“XYZ 末端”模式可编辑基座
坐标系绝对目标位置和 quaternion 姿态，后端先用官方 KDL IK 求解并在半透明
模型中预览，确认后才执行。

控制区有一条十档速度滑条，每次打开页面回到 `10%`，档位为
`1%、2%、3%、4%、5%、10%、25%、50%、75%、100%`。`100%` 对应 SDK 公布的硬件
速度上限，其余档位从同一基准按百分比缩放，并按固定控制周期插值保持轨迹连续。
它控制关节、XYZ 和回参考；网页不再附加固定的
XYZ 距离或单次关节角度上限，实际目标仍必须通过 IK、软件关节限位、轨迹速度、扭矩和
反馈检查。夹爪工具常驻在 3D 控制区底部，第三种控制模式为 `Hand`。

XYZ 执行默认使用“平滑曲线”：先按 100% 求解并验证一条关节空间 Ruckig 曲线，再
按速度档位做时间缩放和固定周期 Hermite 插值；需要严格路径时可切换为“末端直线”，
连续求解并验证全部 IK 中间点。网页 Cartesian 单次最长 `300 s`。

键盘：`M` 循环切换 XYZ/关节/Hand 模式；非 Hand 模式下，`D` 以位置控制张开 5 mm，`F` 使用网页设置的
电机估算扭矩限扭矩闭合（最低开度仅约束行程），`N` 回参考并主动保持。XYZ 模式下 `F`
聚焦目标，`Enter` 仅确认目标编辑，`Esc` 恢复当前编辑阶段；执行始终需要点击“执行预览”。

回参考同样采用两次确认：第一次点击按钮或按 `N` 显示紫色半透明参考姿态和
TCP 轨迹，第二次执行并在完成后继续主动保持；执行期间 TCP 操作器跟随实际反馈。
回参考结束时机械臂和夹爪都会恢复连接时记录的参考状态。

一键叠放使用独立的 `cube.preview-stack` / `cube.stack` 命令。后端先冻结源方块、
目标方块、任务起始参考位和速度，一次规划接近、夹取后搬运、放置撤离及回参考轨迹；
连续移动点使用圆角过渡，只在夹紧、释放和最终参考位停稳。任一预检失败都不会运动，
完整预览有效期为 10 分钟；执行中的可恢复错误会保持当前位置，正常结束恢复机械臂与
夹爪参考状态并主动保持。

切换到“单关节”后仍可点击连杆预览，或按住 `Space` 拖动。运动期间白色模型
会平滑追踪实机反馈，原来的六关节滑块保留在折叠的高级调试区。
MediaPipe 在 Mac 浏览器本地运行。只有选择 Hand、连接机械臂、双手有效、张开手掌
离合接通且“机械臂跟随”已开启时才会发送真实伺服目标；开关关闭时只生成服务端
验证的 Ghost，不调用电机命令。
