# 标定

本项目有两套互不依赖的标定：末端负载重力标定，和 D405/D455 双相机手眼标定。
两者都可以从网页控制台启动，也都有对应的终端入口。

## 末端工具与负载标定

官方 `X5` 连杆参数保持不变。当前固定工具作为基线；腕部相机或夹取物体作为新增
payload，使用相同姿态下的 `loaded - baseline` 扭矩差单独估计质量和 TCP 坐标系
下的重心。网页状态栏的负载菜单可以直接启动“固定负载”或“夹取物体”重新标定；
服务会先确认机械臂已断开，再临时独占 `can0`，完成后写入独立标定目录。

首次为当前固定工具示教一个安全中心并采集基线：

```bash
cd /home/r2/work/projects/embodied/arx5_test
./arx5 calibrate-payload teach
./arx5 calibrate-payload capture baseline
```

只有基线确实是原厂标准夹爪时，才可用 `./arx5 calibrate-payload fit-tool` 额外
检查官方 `link6` 有效质量；这一步不是新增 payload 辨识的前置条件。

`teach` 阶段只读取手动摆好的中心姿态，不自动移动。它生成中心附近 11 个有界的
J4/J5/J6 激励姿态，并检查关节限位和 TCP 运动范围。`capture` 会要求输入 `RUN`，
随后以低速自动回放这些姿态；开始前 J1-J3 必须在示教中心 5° 内，腕部必须在
20° 内，每个姿态静止采样后先回中心。须确保整个运动包络远离桌面、相机和人员，
并准备物理急停。连接时官方重力补偿仍可能让机械臂轻微改变姿态。

安装相机或稳定夹取物体后，保持安装状态和示教计划不变，再采集带载数据。
网页中可在底部状态栏点击重量图标，填写档案名后选择“固定负载”或“夹取物体”。
界面会分阶段要求摆到中心、确认 `RUN`，夹取物体还会要求在释放夹爪前托住物体。
首次示教计划和空载基线仍建议使用下面的终端命令完成：

```bash
./arx5 calibrate-payload capture loaded
./arx5 calibrate-payload fit-payload --profile d455
```

如果负载由夹爪夹持而非刚性安装，baseline 与 loaded 应尽量使用相同夹爪开度，
并在两次采集时加 `--hold-gripper`，例如：

```bash
./arx5 calibrate-payload capture loaded --hold-gripper
```

采集结束前程序会要求先托住物体，再释放夹爪保持；急停或异常阻尼也会立即释放，
因此采集全程都要准备承托物体。

每次拟合会保存一个命名负载档案并设为当前档案。相同安装状态或物体以后无需重测，
直接切换档案即可；`none` 表示当前没有新增负载：

```bash
./arx5 calibrate-payload profiles
./arx5 calibrate-payload use-profile d455
./arx5 calibrate-payload use-profile none
```

网页底部状态栏会显示当前档案和标定质量，hover 可查看 TCP 重心及拟合误差。这个
数值来自保存的静态标定，不是夹爪实时称重，也不会自动写入 SDK 重力补偿。

结果默认保存在 `calibrations/payload/`，命名档案位于其 `profiles/` 目录。
`tool-result.json` 给出固定末端的有效质量；`payload-result.json` 给出新增负载
质量、TCP 重心、拟合误差和条件数。
结果不会自动改写 URDF、重力补偿或正常控制参数，需要确认数据质量后再应用。
这套静态重力流程只辨识质量和重心（一阶矩）；若要为高速动态控制辨识转动惯量，
需要另行设计动态激励和验证，不应直接套用这里的结果。

## D405/D455 双相机手眼标定

网页标定使用同一块 ArUco 板分两段求解：板固定桌面时标定眼在手 D405 的
`T_eef_camera`；板固定夹爪时标定外部 D455 的 `T_base_camera`。工具采用 OpenCV
robot-world/hand-eye 求解，使用 RealSense 当前数据流的出厂内参。网页同时显示闭环
残差、留一法稳定度、Bootstrap 覆盖敏感性，以及不参与拟合的独立重定位误差。独立重定位
是主要效果指标；Bootstrap 只提示某些几何方向是否缺少冗余，不用于自动删样或采用结果。

两台相机的样本、求解、独立验证和启用外参彼此独立；但同一台机械臂与同一块标定板在
D405 阶段必须固定桌面、在 D455 阶段必须刚性夹持，因此物理采集必须串行，不能并行驱动。

```bash
UV_PROJECT_ENVIRONMENT=.venv-handeye uv sync --only-group handeye
./arx5 calibrate-hand-eye generate-target  # 默认 DICT_4X4_50 / ID 0 / 100 mm
./arx5 calibrate-hand-eye capture --confirm-safe
```

终端 `capture` 保留单相机 D455 人工采样，运行前必须关闭网页服务，释放 D455 和
`can0`；双相机自动流程应使用网页入口。完整打印尺寸、安装方式、矩阵方向和复算说明见
[src/hand_eye_calibration/README.md](../src/hand_eye_calibration/README.md)。

### 网页自动标定流程

开始前把板刚性固定在桌面，自由阻尼摆好机械臂，使 D405 完整看到 marker。点击
“开始双相机标定”后，D405 连续三帧检查通过即自动执行联合平移/旋转的多姿态采样，
每点采集后回到本阶段起点。每个独立几何姿态采集 `3 × 20` 帧 burst，并对三次稳健
平均；重复 burst 只降低该姿态的视觉噪声，不会虚增几何样本数。第一段采集 20 组有效
姿态后，流程执行 6 组不参与拟合的独立重定位测试，网页显示评审结果，可由操作者选择
采用或补采 4 组新的多样化姿态。补采会根据当前实测 EEF 位姿的 6D 信息弱方向，从尚未
访问的安全端点中重新选择联合平移/旋转姿态，而不是删除高影响样本。随后流程张开夹爪
并提示把同一块板从桌面移入夹爪；
`0.30 N·m` 限扭矩夹紧后，手动摆到 D455 可见安全中心并确认，第二段自动开始。

20 组有效姿态是自动阶段的停止条件，不再由误差阈值自行决定采用或无限采样；所有阈值
仍显示为诊断警告，基础可观测性、标定板检测、实测稳定性和硬件安全检查仍会保留。两段
正常结束都回各自起点，最后进入阻尼。普通取消返回当前阶段起点；若板在夹爪中，等待
人工托住后再释放。急停、浏览器断开和服务退出立即进入阻尼。
