# Robot Teleoperation Phase 0 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build and verify the hardware-free Phase 0 foundation for a modular, low-latency robot teleoperation framework.

**Architecture:** Use a pure canonical core and dependency-inverted ports, composed by a single-process threaded runtime. Receiver-to-servo transfer is latest-only; relative clutch mapping, safety, state, watchdog, and metrics each have one owner.

**Tech Stack:** Python 3.12, standard-library geometry/threading, PyYAML, uv, Ruff, mypy, pytest, GitHub Actions.
