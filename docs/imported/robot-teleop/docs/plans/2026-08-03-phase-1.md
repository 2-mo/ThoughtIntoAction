# Robot Teleoperation Phase 1 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build and verify the Python binary-protocol and latest-only Ubuntu UDP path from ARKit-format datagrams to MockRobot.

**Architecture:** Add fixed v1 Pose/Ping/Pong codecs behind the existing Transport and TeleopInputSource ports. `UdpTransport` discards superseded datagrams, `ArkitInputSource` owns decoding and sequence/session validation, and the existing Receiver/Servo/MockRobot path remains unchanged below canonical input.

**Tech Stack:** Python 3.12 standard-library `struct`, `socket`, threading and monotonic clocks; PyYAML; uv; Ruff; strict mypy; pytest.
