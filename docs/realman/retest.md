# RealMan 当前版本真机复测

本清单针对标准平台 `robot-pair`，左臂 `.19`、右臂 `.18`，不使用独立 `realman quest/quest-dual` 诊断入口代替验收。2026-11-06 修复了5项因25Hz旧假设导致的测试失败，相关两组离线回归共60项通过，覆盖25/50Hz；此次未修改控制逻辑，未执行真机运动。

当前真机为50Hz低跟随，关节预算最多180°/s、3.6°/周期，实际还受控制器读回限制；实时跟随不额外截断TCP速度，不能按旧文档假定0.25m/s是遥操的硬上限。首次复测只做小幅慢动作，先单侧后双侧，确认机械臂、线缆及整个回位路径有空间，现场操作者能够使用物理急停。平台没有双臂碰撞检测。

## 启动与确认版本

所有命令在仓库根目录执行：

```bash
cd /home/guest/下载/ThoughtIntoAction-local
./run.sh
```

代码不会热更新已有内核。在总控按 **S** 停止原双臂，再按 **6** 启动真机并完成启动确认；已停止则直接按6。先松开所有按键，不在启动时握Grip或按Trigger。确认左右均为真实反馈、关节数为6、手柄在线，启动不应自动移动或张开夹爪。只有一侧夹爪未就绪时应显示未知宽度，该侧机械臂仍可读状态；不要把它算作开合通过。

运行目录由启动终端打印，也可只读查看：

```bash
cat outputs/runtime/realman/pair.json
```

记下左右RUN、测试开始时间和当前提交号 `git rev-parse HEAD`。本次重启后应生成新的RUN；旧日志不能作为新版本证据。

## 按顺序复测

1. **待机30秒。** 两臂和夹爪均不操作，确认网页持续更新、姿态保持、无组件退出或故障。左右分别用X/A按住至少150ms后松开切换本侧模式，按界面确认进入跟随；另一侧保持。
2. **单侧跟随与重定位。** 先左后右，Grip握住后慢移1～2cm，分别检查前后、左右、上下，再做小角度转腕。以人站在机械臂后方、面向作业区为参照，前移对应-X，右移对应+Y，上抬对应+Z。松Grip应保持；把手柄换个位置重新握住，不应跳回上一段未到达的目标。未操作侧应保持。
3. **单侧夹爪完整开合。** 两臂保持不动、夹爪空载且有张开空间。进入本侧跟随后，先松Trigger再按下解锁，逐渐按到底闭合，再完全松开张开，每侧做5轮，核对真实夹指与网页宽度一致。宽度是名义70mm换算，不是指尖标定。张开前重新按闭合也应在当前动作完成后采用最新目标，不应永久无响应。运动中换向可能等待当前动作完成，不能要求即时反向。
4. **停止打断后的恢复（本轮重点）。** 在单侧夹爪刚开始张开时，用本侧X/A切到保持，确认界面已保持；等待至少8秒，检查双臂内核仍在线。松开所有按键，再切回跟随，松Trigger后重新按下，确认可再次闭合、张开，不会在下一次操作时报旧目标超时。每侧做3轮。已接受的夹爪动作可能继续到目标，Grip松开、模式切换或机械臂停止都不保证夹爪即时停住。
5. **接触后重新开合。** 前项通过后，用适合夹持的软质测试物验证一次接触停止，手指远离夹指。随后完全松Trigger张开，在张开过程中重新按闭合，再松开。应先完成当前动作，再响应最新目标，不应因旧接触标记持续拒绝闭合；不得为了通过测试绕过真实故障或增加夹紧力。
6. **Y/B回位单独验证。** 先确认整段回位路径无障碍，松Grip、Trigger及功能键，单独按住本侧Y/B至少1秒；应仅该臂朝 `[0,0,90,0,90,0]°` 回位，继续按住至到位，松开停止，夹爪不动。先测松键中止，再测完整到位。Y/B不用于夹爪初始化；若路径无法确认，记录此项未测。
7. **双侧并发与稳定性。** 前项分别通过后，在两臂互不接近的区域，小幅跟随并交替开合至少2分钟。确认没有双侧联停、反馈过期退出、持续反向或跳变；记录实际持续时间和各侧动作次数，不能只以“网页仍打开”判断通过。
8. **输入断流保护。** 先松Grip并等待夹爪停止，再让Quest休眠，确认输入过期后撤权并保持。唤醒后不应自动接续旧目标，按界面要求显式重新启动输入会话再操作；不在运动中拔机械臂网线来模拟此项。

任一项出现非预期运动，现场停止测试并按需使用物理急停；保留对应RUN和时间点。真实故障应继续报错，不把屏蔽超时或自动重连当作修复。

## 相机与采集另行验收

先确认三路真实RGB和深度预览正常，左腕视角确实覆盖作业区。总控用 **[ / ]** 选择要记录的机械臂；以下命令中把 `<RUN>` 替换为该侧新运行目录：

```bash
./run.sh collect run --run <RUN> --task RealMan三相机复测 \
  --cameras wrist_rgb,right_wrist_rgb,exterior_rgb --rgb mp4 --duration 20
```

预期在 `outputs/datasets/runtime/episode_*/` 生成三路MP4及MCAP帧索引；查看采集完成状态并实际回放三路视频，确认没有缺路或冻结。这仍是一侧机械臂状态加三路图像，不是双臂联合状态记录。手眼／固定相机外参尚需单独标定，本清单不把视频出图当作标定通过。

## 保留证据与判断结果

在每侧RUN保留 `backend.log`、`backend-parameters.json`、`parameters.json`、`runtime.json`，以及同目录已有的控制轨迹；双臂监督日志位于启动时打印的 `outputs/runtime/realman/pair-*/`。正常停止本次双臂后，查看每侧 `report.json` 的错误、周期统计和停止结果。夹爪停止打断用例中，停止确认后应清除旧目标；日志可能出现“EG2停止反馈已确认”，需要结合实际开合恢复判断，单条日志不是通过证据。

逐项记录左右结果、实际次数、异常时间和RUN。涉及未就绪、退出、超时或未执行的项均不能记为通过；如出现 `RealMan feedback expired during target calculation`、`EG2 position feedback did not reach the accepted segment` 或 `EG2 segment still moving after 5 s`，保留原始错误，停止后续依赖步骤。
