# Robot Teleoperation Phase 2 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build a simulator-first Swift/SwiftUI ARKit client that sends the shared binary protocol directly to Ubuntu and is ready for iPhone validation.

**Architecture:** A simulator or ARKit `PoseProvider` feeds one shared coordinator, strict codec, latest-only Network.framework UDP client, and operational SwiftUI model. A small additive Settings control plane updates canonical Ubuntu mapping scales without moving mapping logic into the app.

**Tech Stack:** Swift 6, SwiftUI, Observation/Combine, ARKit, Network.framework, XCTest, Xcode 26.6, iOS 26.0 deployment target, Python 3.12, uv, pytest, Ruff, and strict mypy.
