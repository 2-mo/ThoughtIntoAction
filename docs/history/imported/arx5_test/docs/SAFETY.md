# 保护边界

这些软件保护不能替代物理急停、现场隔离和机械限位。

## 关节

- 网页 `100%` 档以 X5 SDK 上限为基准：六关节分别为
  `[5, 5, 5.5, 5.5, 5, 5] rad/s`，末端平移为 `0.6 m/s`，夹爪为
  `0.3 m/s`。其余档位从同一个 100% 基准按百分比缩放，页面和服务端默认 `10%`。
- Cartesian 轨迹先按 100% 生成并验证一次，再按 `1 / speed` 缩放时间、按 `speed`
  缩放命令速度；慢速会按固定控制周期增加五次 Hermite 插值点，保持位置、速度和
  加速度连续。
- 回参考、关节、XYZ 和夹爪动作都继续执行软件限位、扭矩、反馈和故障阻尼保护。

## XYZ

- XYZ 不设固定单轴或合成距离上限。“平滑曲线”使用完整的关节空间 Ruckig
  轨迹，不保证末端中途为直线；“末端直线”预计算并验证全部笛卡尔 waypoint。
  两者都在发送前验证完整轨迹，具体可达范围由 IK、软件关节限位和轨迹时长决定。
- Pinocchio 负责解析 FK/Jacobian；奇异区自动降速，严重奇异路径直接拒绝。
- 默认使用软件关节限位、IK/FK 残差、奇异性、轨迹动力学和 TCP primitive 障碍检查。
  未标定的保守 capsule 容易误拒绝正常姿态，因此整臂自碰撞默认关闭。
- 显式设置 `ArmController(enable_link_collision=True)` 可启用 Coal capsule 检查；默认
  link 安全间隙是 `3 mm`，关节路径最多每 `0.5 deg` 插值检查一次。
- waypoint blend 使用相切圆弧。无效半径、重叠 blend、碰撞圆弧会在发送前拒绝。
- Cartesian 几何按空间距离和姿态距离固定采样；同一预览的各速度档位复用同一组 IK
  锚点。慢速执行只重采样时间参数，不重新求解不同路径。
- collision capsule 是保守软件模型，必须通过低速真机标定；不能替代急停和现场隔离。

## 夹爪

- 夹爪 `100%` 位置规划上限为 `0.3 m/s`，并随速度档位缩放。限扭矩闭合默认
  0.15 N·m、网页上限 `0.25 N·m`，
  最低开度是行程约束而不是夹持力目标。
- 这里的 N·m 是 SDK 根据电流估算的电机扭矩，不是标定后的指尖夹持力 N。

## 手势遥操作

- 默认 TCP 安全盒为基座坐标 `X 0.15–0.65 m`、`Y -0.35–0.35 m`、
  `Z 0.08–0.55 m`；距离边界 `30 mm` 内连续降速，越界目标拒绝但不让伺服线程
  故障。绿色线框显示同一份服务端配置，红色 Ghost 表示当前手势目标不可达。
- “精细”档的平移/旋转增益为 `0.5/0.6`，TCP 线速度上限 `0.03 m/s`，关节速度
  上限 `1.5 rad/s`；“快速”档为 `1.0/1.0`、`0.10 m/s` 和 `3.5 rad/s`。
  两档都由服务端限制关节加速度、跃度和 TCP 角速度，浏览器参数不能绕过这些上限。
- 左手张开时，相对零位偏移经死区和低通后控制 TCP 线速度与角速度；回到零位即保持，
  不返回旧位置。左手握拳会停车，下次张开时以机械臂当前位置重设零位。双手置信度
  不足、离开 Hand 模式、切换手眼标定、页面隐藏、摄像头停止或控制 WebSocket
  断开都会发起停车。
  新目标超过 `200 ms` 未到达时，服务端看门狗同时平滑制动机械臂和夹爪。
- 夹爪闭合扭矩网页允许 `0.05–0.25 N·m`，默认 `0.15 N·m`；接触扭矩达到设置值
  后锁存制动，直到收到张开手势。该数值仍是电机估算扭矩，不是指尖力。
- “机械臂跟随”关闭时使用独立的只读预览会话，只计算服务端 IK Ghost，不调用
  电机伺服命令。首次实机必须先在该状态核对轴方向和安全盒。

## 运行时

- 反馈超速、超扭矩、时间戳停滞或越界会立即进入故障阻尼。
- 允许大范围的网页 Cartesian 操作单次最长 `300 s`；超过上限会在预览阶段拒绝，
  不会伪装成加速度或 IK 故障。
- `/tmp/arx5-control-can0.lock` 防止两个本项目控制器同时占用 CAN。
- 所有自动抓取都是两段式：第一次点击只做连续 IK 预检并显示真实 TCP 路径，
  第二次才发送运动；预检后机械臂姿态或目标位置变化会让动作包自动失效。
- 网页配对令牌保存在 `runtime/web-pairing-token`。持有令牌等同于持有控制权，
  不要写进仓库、截图或聊天记录。
- 网页急停和软件看门狗都不能替代实体急停。直接切断机械臂电源会立即失去保持力，
  机械臂、夹具或负载可能坠落；只有人员与设备已离开坠落区时才可直接断电。

## 参数来源

`src/backend/arx5_backend/kernel/control.py` 的 `WEB_MOTION_SAFETY` 定义网页运动基准，底层字段和
校验由 `src/arx5_control/controller.py` 的 `SafetyConfig` 提供。构造时逐项校验正负与
有限性，并检查伺服速度上限不超过规划上限、且低于反馈超速阈值。抓取几何和桌面边界的唯一定义处是
`src/experiments/cube_pick_rotate_place/planner.py`。
